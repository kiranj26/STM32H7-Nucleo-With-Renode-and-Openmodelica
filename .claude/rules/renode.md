# Renode rules

## Files
- `projects/pN_*/renode/pN.resc` is the single entry script and must run headless (`renode --disable-xwt --console pN.resc`). `.resc` has no conditionals, so GUI extras (`showAnalyzer`) go in `pN_gui.resc`, which `include`s `pN.resc`.
- Platforms: include the upstream `@platforms/cpus/stm32h743.repl`, then layer a **project overlay** (`pN_overlay.repl`) for fixes and additions. Never copy-and-edit the upstream file; the only exception is the P0 `annotated.repl`, which is documentation only.
- Custom peripherals: C# goes in `projects/pN_*/renode/peripherals/*.cs` (loaded with `include @...`). Python peripherals are only for quick prototypes. Each peripheral gets a header comment listing its register map and the reference manual (RM0433) section it follows.
- Variables at the top of every `.resc` use the `$var?=default` form (`$bin`, `$plant_port`), so Robot and the CLI can override them and nothing is hard-coded.

## Time
- **All test timing is virtual time.** Use `emulation RunFor "0.001"` or the Robot `Wait For ...` keywords with `timeout=`. Never use host sleeps (a hook blocks long `sleep`).
- From P4 on, set the quantum explicitly (`emulation SetGlobalQuantum "0.00001"`) and record the value in the README. It is part of the experiment.
- Log virtual time next to host time in every co-sim CSV (`t_virtual_s`, `t_host_s`).

## Debugging order (see the `renode-triage` skill)
1. `logLevel -1 sysbus.<periph>` and `sysbus LogPeripheralAccess sysbus.<periph> true`
2. `cpu PC` and `sysbus FindSymbolAt (cpu PC)` to see where firmware is stuck
3. `sysbus LogAllPeripheralsAccess true` only as a last resort, because it is noisy
4. GDB: `machine StartGdbServer 3333`

## Snapshots (P2+)
- Save after boot reaches the main loop: `Save @snap/pN_ready.save`. Snapshots are gitignored build artifacts and are regenerated by `make test`.
- After `Load`, re-create socket terminals and reconnect the bridge, because external connections are not part of the snapshot.

## Recording
- Every non-obvious monitor command used for the first time gets one line in the project README's "Features used" list, with a link to the line in the `.resc`.
